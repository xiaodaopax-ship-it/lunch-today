# 今天吃什么（静态版）

深圳南山来福士周边的午饭决策器。老黄历 + 每天推荐三家。

手机打开，加到主屏幕就跟 App 一样。

## 这一版能做什么

- 看当天老黄历（农历、干支、值星、宜忌、日五行、午时吉凶、吃运分）
- 看按黄历算出来的三家推荐，带加减分理由
- 换一批、翻到以后任何一天
- 查团购、看地图的跳转链接

## 不能做什么

投票、记录"大家吃了什么"、周报 —— 这些需要一个能写数据的后端，
静态托管做不到。要这些功能就得部署完整版（Flask）。

## 怎么更新数据

数据是用 Python 预生成的（同一套推荐引擎，不是重写的 JS，
所以不会算出不一样的结果）：

```
python _scripts\build_pages.py --days 180
```

然后把生成的 index.html 提交推上去。
